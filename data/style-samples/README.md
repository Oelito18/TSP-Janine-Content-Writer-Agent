# Style samples — haar eigen posts

Hier horen de veertien echte LinkedIn-posts van Janine die als ijkpunt dienen. De agent leest maximaal vijf bestanden per run (`verzamel_samples` in `src/generate_draft.py`) en imiteert daaruit zinsbouw, ritme en toon.

**Status: nog leeg.** De volledige teksten staan niet als tekst in de Drive-map "Project Janine" — de stijlgids verwijst er wel naar, maar de posts zelf zitten er niet als tekstbestand in. Ze moeten alsnog aangeleverd worden (kopiëren vanaf LinkedIn of als export).

## Formaat

Eén post per bestand, platte markdown, geen frontmatter:

```
data/style-samples/01-van-hoodie-naar-driedelig-pak.md
data/style-samples/02-soep-van-de-week-de-wever.md
data/style-samples/03-geen-kpi-geen-dashboard.md
```

Zet de posttekst exact zoals hij op LinkedIn stond, inclusief de unicode-bold hook en de hashtags. Voeg er niets aan toe: elke uitleg die je erin zet, imiteert de agent mee.

Zet de best presterende posts vooraan in de nummering — die worden als eerste ingelezen.
